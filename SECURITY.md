# Security Policy

## Security Status Notice

**Antech KDF is currently an experimental research project.** It is NOT intended for production deployment. The cryptographic constructions inside are under active research and evaluation.

## Reporting a Vulnerability

If you discover a potential security vulnerability (such as a memory corruption issue, panic condition, or timing side-channel in memory comparison), please report it responsibly:

1. **Email**: Send security reports to `security@antech-kdf.org` (or open a confidential security advisory on GitHub).
2. **Details**: Include steps to reproduce, impact, and affected components or crates.
3. **Disclosure**: Please allow reasonable time for investigation before public disclosure.

Do NOT open public GitHub issues for security vulnerabilities.
