```bash
cargo check --workspace
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

Research workspace:

```bash
cargo check --manifest-path research/code/Cargo.toml --workspace
```

Production crates stay under `crates/`. SDKs under `bindings/` and `sdk/`. Experiments under `research/`.

<Note>
Do not change digest behavior, v2 encoding, or public API semantics unless the change is intentional, versioned, and covered by updated vectors.
</Note>

Published docs: [developers.udinmo.com](https://developers.udinmo.com).
