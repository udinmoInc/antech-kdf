```bash
cargo check --workspace
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

Research changes:

```bash
cargo check --manifest-path research/code/Cargo.toml --workspace
```

<Warning>
Do not change canonical digest behavior, v2 format, or public API semantics unless the change is intentional, versioned, and covered by new vectors.
</Warning>

Layout: production under `crates/`, SDKs under `bindings/`, research under `research/`.
