Requires CGO and a visible `libantech_kdf_ffi` (via `ANTECH_KDF_LIB` or linker search paths).

```go
package main

import (
    "fmt"
    antech "github.com/udinmoInc/antech-kdf/bindings/go"
)

func main() {
    h, err := antech.Hash([]byte("password"))
    if err != nil {
        panic(err)
    }
    ok, err := antech.Verify([]byte("password"), h)
    fmt.Println(ok, err)
}
```

Passwords are `[]byte`. Prefer that over assuming UTF-8 strings when integrating with binary secrets.

See [`bindings/go/README.md`](https://github.com/udinmoInc/antech-kdf/blob/main/bindings/go/README.md) in the repository.
