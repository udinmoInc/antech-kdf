Package: `bindings/swift` in the [repository](https://github.com/udinmoInc/antech-kdf/tree/main/bindings/swift). Link `antech_kdf_ffi` and ensure header search paths resolve `antech_kdf.h`.

```swift
let stored = try AntechKdf.hash("password")
let ok = try AntechKdf.verify("password", encodedHash: stored)
```

## Platform notes

| Target | Guidance |
|---|---|
| macOS | Link the platform native library; set `ANTECH_KDF_LIB` if needed |
| iOS | Ship an XCFramework built from the Rust staticlib |

See [`sdk/PLATFORMS.md`](https://github.com/udinmoInc/antech-kdf/blob/main/sdk/PLATFORMS.md) for packaging notes.
