Package: `bindings/swift`. Link `antech_kdf_ffi` and ensure header search paths resolve `antech_kdf.h`.

```swift
let stored = try AntechKdf.hash("password")
let ok = try AntechKdf.verify("password", encodedHash: stored)
```

## Platform notes

| Target | Guidance |
|---|---|
| macOS | Dynamic library from `build-native` is usually enough |
| iOS | Prefer an XCFramework built from the Rust staticlib/cdylib |

See `sdk/PLATFORMS.md` in the repository for packaging details.

<Note>
iOS App Store distribution needs a signed XCFramework workflow. Do not ship unsigned debug natives.
</Note>
