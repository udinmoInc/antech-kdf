Every non-Rust SDK is a thin wrapper over `antech-kdf-ffi`. Digests, validation, and encoding come from the Rust core — not from a second implementation in the binding. That is the whole point of the multi-language surface: one construction, many call sites.

## Shared operations

| Operation | Purpose |
|---|---|
| `hash` | Default 16 MiB profile |
| `hash_with_config` | Explicit structural parameters |
| `verify` | Constant-time check |
| `needs_rehash` / `needs_rehash_with_policy` | Upgrade detection |
| `hash_with_config_and_salt` | Deterministic KATs only |

## Version and native artifacts

Root `VERSION` is authoritative:

```bash
python sdk/scripts/sync-versions.py
./sdk/scripts/build-native.sh   # or build-native.ps1
```

CI uploads per-OS natives on `v*` tags. Platform notes live in `sdk/PLATFORMS.md` in the repository.
