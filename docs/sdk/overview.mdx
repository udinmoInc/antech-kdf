Every non-Rust SDK is a thin wrapper over `antech-kdf-ffi`. Digests, validation, and encoding come from the Rust core — not from a second implementation in the binding language.

## Current version

All published packages track release **0.1.0**. Verify the version in your dependency manager before deploying.

| Language | Package | Install |
|---|---|---|
| Rust | `antech-kdf` | `cargo add antech-kdf@0.1` |
| Python | `antech-kdf` | `pip install antech-kdf==0.1.0` |
| Node / TypeScript | `antech-kdf` | `npm install antech-kdf@0.1.0` |
| .NET | `Antech.Kdf` | `dotnet add package Antech.Kdf --version 0.1.0` |
| Go | module under `bindings/go` | see [Go SDK](./go) |
| Java / Kotlin | JNA binding | see [Java / Kotlin SDK](./java-kotlin) |
| Swift | SwiftPM package | see [Swift SDK](./swift) |
| C / C++ | headers + native library | see [C / C++ SDK](./c-cpp) |
| PHP | `bindings/php` | Composer + `ext-ffi` |
| Ruby | `bindings/ruby` | gemspec + `ffi` |
| Dart | `bindings/dart` | `dart pub get` |
| Perl | `bindings/perl` | `FFI::Platypus` |
| R | `bindings/r` | `.Call` shim |
| Lua (LuaJIT) | `bindings/lua` | `require("antech_kdf")` |
| Zig / Crystal / Nim | `bindings/{zig,crystal,nim}` | link C ABI |
| Julia | `bindings/julia` | `ccall` |
| Haskell | `bindings/haskell` | Cabal FFI |

Changelog: [CHANGELOG.md](https://github.com/udinmoInc/antech-kdf/blob/main/CHANGELOG.md).

## Shared operations

| Operation | Purpose |
|---|---|
| `hash` | Default 16 MiB profile |
| `hash_with_config` | Explicit structural parameters |
| `verify` | Constant-time check |
| `needs_rehash` / `needs_rehash_with_policy` | Upgrade detection |
| `hash_with_config_and_salt` | Deterministic KATs only |

## Native library

FFI-based SDKs load `antech_kdf_ffi` at runtime. If automatic discovery fails, set `ANTECH_KDF_LIB` to the directory containing the library for your platform. Platform notes: [`sdk/PLATFORMS.md`](https://github.com/udinmoInc/antech-kdf/blob/main/sdk/PLATFORMS.md) in the repository.
