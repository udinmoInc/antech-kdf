Rust owns the cryptographic implementation. Prefer this crate for Rust services; use FFI only when another language must call in.

```toml
[dependencies]
antech-kdf = "0.1"
```

```rust
use antech_kdf::{hash, verify, needs_rehash, hash_with_config, AntechConfig};

let stored = hash("secret")?;
assert!(verify("secret", &stored)?);

let cfg = AntechConfig::builder().memory_mib(16).build()?;
let custom = hash_with_config("secret", &cfg)?;
let _ = (needs_rehash(&stored)?, custom);
```

## Surface to expect elsewhere

| Rust | Typical binding name |
|---|---|
| `hash` | `hash` / `Hash` |
| `verify` | `verify` / `Verify` |
| `needs_rehash` | `needs_rehash` / `NeedsRehash` |
| `AntechConfig` | `Config` / POD struct |
| `RehashPolicy` | `RehashPolicy` |

Passwords are `AsRef<[u8]>`. Prefer bytes over assuming UTF-8 when integrating with password managers or binary secrets.
