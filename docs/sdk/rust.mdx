```toml
[dependencies]
antech-kdf = "0.1"
```

```rust
use antech_kdf::{hash, verify, needs_rehash};
let h = hash("secret")?;
assert!(verify("secret", &h)?);
```

Rust is the source of truth. Other SDKs mirror this surface through FFI.
