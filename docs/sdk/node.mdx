```bash
npm install antech-kdf@0.1.0
```

Confirm with `npm list antech-kdf`.

```typescript
import {
  hash,
  verify,
  hashWithConfig,
  defaultConfig,
  needsRehash,
  needsRehashWithPolicy,
  defaultRehashPolicy,
} from "antech-kdf";

const stored = hash("password");
verify("password", stored);

const cfg = defaultConfig();
cfg.memory_kib = 1024;
const custom = hashWithConfig("pw", cfg);

const policy = defaultRehashPolicy();
policy.preferred_memory_kib = 32768;
needsRehashWithPolicy(custom, policy);
```

Naming is camelCase in TypeScript; semantics match Rust and Python. Set `ANTECH_KDF_LIB` if the native library is not found automatically.

<Warning>
Do not call `hash` / `verify` on the main Node event-loop tick under load. Offload to a worker thread.
</Warning>
