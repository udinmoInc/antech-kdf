Canonical cases live in `sdk/conformance/vectors.json` (derived from the security-review test vectors). Every language package that claims Antech compatibility must match these digests bit-for-bit.

## What each package must prove

1. `hash_with_config_and_salt(password, salt, config)` returns a `$antech$v2$…` string
2. The digest hex (final `$` field) equals `digest_hex`
3. `verify(password, encoded)` is true
4. Malformed hashes map to the shared invalid-hash error

## Runners

```bash
cargo test -p antech-kdf conformance -- --nocapture
python sdk/conformance/run_python.py
```

CI workflow `.github/workflows/sdk.yml` runs Rust and Python conformance across OSes after building natives.
