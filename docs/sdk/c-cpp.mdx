Include `bindings/c/antech_kdf.h` and link `antech_kdf_ffi`. Headers and examples are in the [repository](https://github.com/udinmoInc/antech-kdf/tree/main/bindings/c).

## C

```c
char *out = NULL;
if (antech_hash("password", &out) == ANTECH_OK) {
  /* use out */
  antech_free(out);
}
```

Prefer `antech_hash_bytes` / `antech_verify_bytes` when passwords are arbitrary binary. Empty passwords are allowed with length `0`.

## C++

```cpp
#include "antech_kdf.hpp"
auto h = antech::hash("password");
assert(antech::verify("password", h));
```

Header-only wrapper: `bindings/cpp/antech_kdf.hpp`.

Obtain the native library for your platform through the published SDK distribution or set `ANTECH_KDF_LIB` / linker paths accordingly. Platform notes: [`sdk/PLATFORMS.md`](https://github.com/udinmoInc/antech-kdf/blob/main/sdk/PLATFORMS.md).

<Tip>
Free strings with `antech_free` in C. The C++ helpers free automatically.
</Tip>
