```bash
pip install antech-kdf==0.1.0
```

Confirm with `pip show antech-kdf`. Requires Python 3.9+.

```python
import antech_kdf

stored = antech_kdf.hash("correct_horse_battery_staple")
assert antech_kdf.verify("correct_horse_battery_staple", stored)

cfg = antech_kdf.Config.default()
cfg.memory_kib = 1024
custom = antech_kdf.hash_with_config("pw", cfg)

policy = antech_kdf.RehashPolicy.default()
policy.preferred_memory_kib = 32768
needs = antech_kdf.needs_rehash_with_policy(custom, policy)
```

The package loads `antech_kdf_ffi` at runtime. Set `ANTECH_KDF_LIB` if the native library is not on the default search path.

## Conformance

After install, run the shared KAT suite from a repository checkout:

```bash
python sdk/conformance/run_python.py
```

Expect **12/12** when the native library matches release **0.1.0**.
