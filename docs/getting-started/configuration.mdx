Structural parameters live on `AntechConfig`. Builders in Rust and POD structs in FFI validate the **same** bounds, so a rejected config in Python is a rejected config in Go.

There is no separate iteration-count knob. Work equals `memory_bytes / block_size` and must yield **at least 64** blocks.

## Builder

```rust
use antech_kdf::{hash_with_config, AntechConfig, GraphKind};

let config = AntechConfig::builder()
    .memory_mib(16)
    .salt_length(16)
    .block_size(32)
    .fan_in(2)
    .graph(GraphKind::CombinedFrontier)
    .output_length(32)
    .build()?;

let stored = hash_with_config("password", &config)?;
```

## Parameter table

| Field | Default | Bounds |
|---|---|---|
| Memory | 16 MiB (`16384` KiB) | 1024…1 048 576 KiB |
| Salt length | 16 B | 8…256 |
| Block size | 32 B | ≥ 16, power of two |
| Fan-in | 2 | 2…8 |
| Graph | CombinedFrontier | tags `1`, `2`, `3` |
| Output length | 32 B | 8…128 |

<Note>
Changing memory or block size is how you change work. Do not invent an extra loop around `hash` and treat that as a security parameter — you would only amplify latency for legitimate logins.
</Note>

## Graph tags

| Tag | Name | Use |
|---|---|---|
| `3` | CombinedFrontier | Production default and review target |
| `1` | ReducedCriticalPath | Research contrast |
| `2` | CacheLocality | Research contrast |

Keep `CombinedFrontier` unless you are deliberately studying alternatives. Digests change when the graph changes because the kind is mixed into the seed.

## How knobs interact

```text
num_blocks = memory_bytes / block_size
work       ≈ O(num_blocks × mix_cost × fan_in edges)
```

Raising memory increases both RAM and CPU time. Shrinking block size increases the number of nodes for the same memory budget — useful for experiments, rarely needed for default auth profiles.

## FFI field names

When you fill `AntechConfig` from C or ctypes, use KiB for memory and the numeric graph tag:

```c
AntechConfig cfg;
antech_config_default(&cfg);
cfg.memory_kib = 16384;
cfg.graph = ANTECH_GRAPH_COMBINED_FRONTIER; /* 3 */
```

<Warning>
Invalid combinations fail closed (`ANTECH_INVALID_CONFIG` / Rust `Error::InvalidConfig`). Do not catch and silently fall back to weaker parameters.
</Warning>
