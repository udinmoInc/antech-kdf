Antech KDF is an experimental password hashing library built around a **compute-memory** construction. The default profile uses **16 MiB** of working memory and a **combined-frontier** dependency graph. Work is derived from `memory / block_size` — there is no separate iteration-count knob.

<Warning>
Antech has not completed independent cryptographic review. Prefer Argon2id for production password storage until review conclusions are published. Treat benchmarks as comparative evidence, not a security proof.
</Warning>

## What you get

- Stable Rust API: `hash`, `verify`, `needs_rehash`, `hash_with_config`, and rehash policies
- Self-describing `$antech$v2$…` stored hashes
- Thin SDKs for C/C++, Go, Python, Node, Java/Kotlin, Swift, and .NET over one FFI
- Shared conformance vectors so every language matches the same digests

## Single source of truth

Cryptography lives only in `antech-kdf-core`. Language packages call `antech-kdf-ffi` and never reimplement the engine.
