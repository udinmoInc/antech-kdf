## Hash, verify, rehash check

```rust
use antech_kdf::{hash, verify, needs_rehash};

fn main() -> Result<(), antech_kdf::Error> {
    let password = "correct_horse_battery_staple";
    let stored = hash(password)?;

    assert!(verify(password, &stored)?);
    assert!(!verify("wrong_password", &stored)?);
    assert!(!needs_rehash(&stored)?);

    println!("{stored}");
    Ok(())
}
```

What you just used:

- **16 MiB** working memory
- Block size **32**, fan-in **2**
- Graph **CombinedFrontier** (`g=3` in the encoded string)
- Random salt, **32**-byte digest

## Same idea in other languages

<FrameworkTabs frameworks={['Python', 'TypeScript', 'Go']}>
  <FrameworkContent framework="Python">
    ```python
    import antech_kdf

    stored = antech_kdf.hash("correct_horse_battery_staple")
    assert antech_kdf.verify("correct_horse_battery_staple", stored)
    assert not antech_kdf.needs_rehash(stored)
    ```
  </FrameworkContent>
  <FrameworkContent framework="TypeScript">
    ```typescript
    import { hash, verify, needsRehash } from "antech-kdf";

    const stored = hash("correct_horse_battery_staple");
    verify("correct_horse_battery_staple", stored); // true
    needsRehash(stored); // false under default policy
    ```
  </FrameworkContent>
  <FrameworkContent framework="Go">
    ```go
    h, err := antech.Hash([]byte("correct_horse_battery_staple"))
    ok, err := antech.Verify([]byte("correct_horse_battery_staple"), h)
    ```
  </FrameworkContent>
</FrameworkTabs>

<Tip>
Passwords are bytes in the Rust API (`AsRef<[u8]>`). Prefer byte-oriented FFI helpers when passwords may contain interior NUL bytes.
</Tip>
