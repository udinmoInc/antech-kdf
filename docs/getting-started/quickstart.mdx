This quickstart uses the Rust API. Other SDKs expose the same operations with native naming.

## Hash and verify

```rust
use antech_kdf::{hash, verify, needs_rehash};

fn main() -> Result<(), antech_kdf::Error> {
    let password = "correct_horse_battery_staple";
    let stored = hash(password)?;
    assert!(verify(password, &stored)?);
    assert!(!needs_rehash(&stored)?);
    println!("{stored}");
    Ok(())
}
```

Defaults: **16 MiB**, block size **32**, fan-in **2**, graph **CombinedFrontier**, salt length **16**, output **32** bytes.

## Wrong password fails closed

```rust
assert!(!verify("wrong_password", &stored)?);
```
