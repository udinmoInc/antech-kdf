A practical auth path has three library calls: hash on registration, verify on login, and an optional rehash when your policy says the stored parameters are behind.

## Sequence

<Mermaid chart={`
sequenceDiagram
    participant App
    participant Antech
    participant DB
    App->>Antech: hash(password)
    Antech-->>App: antech v2 string
    App->>DB: store encoded hash only
    App->>DB: load encoded hash
    App->>Antech: verify(password, hash)
    Antech-->>App: true or false
    App->>Antech: needs_rehash_with_policy
    alt upgrade needed
        App->>Antech: hash_with_config(password, stronger)
        App->>DB: replace encoded hash
    end
`} />

## Registration

```rust
let stored = antech_kdf::hash(password)?;
// persist `stored` — never the password, never a separate parameter blob
```

The string already carries memory, graph, salt, and digest. `verify` rebuilds config from it.

## Login with optional upgrade

```rust
use antech_kdf::{
    hash_with_config, needs_rehash_with_policy, verify, AntechConfig, RehashPolicy,
};

if !verify(password, &stored)? {
    return Err(/* authentication failure */);
}

let policy = RehashPolicy::builder()
    .minimum_memory_mib(16)
    .preferred_memory_mib(32)
    .build();

if needs_rehash_with_policy(&stored, &policy)? {
    let stronger = AntechConfig::builder().memory_mib(32).build()?;
    let upgraded = hash_with_config(password, &stronger)?;
    // replace the row in your user store
}
```

<Tip>
Rehash only after a successful verify. Wrong passwords should not force expensive upgrades.
</Tip>

## Multi-language sketch

<FrameworkTabs frameworks={['Python', 'C#']}>
  <FrameworkContent framework="Python">
    ```python
    import antech_kdf

    if not antech_kdf.verify(password, stored):
        raise AuthError()

    policy = antech_kdf.RehashPolicy.default()
    policy.preferred_memory_kib = 32768
    if antech_kdf.needs_rehash_with_policy(stored, policy):
        cfg = antech_kdf.Config.default()
        cfg.memory_kib = 32768
        stored = antech_kdf.hash_with_config(password, cfg)
    ```
  </FrameworkContent>
  <FrameworkContent framework="C#">
    ```csharp
    if (!AntechKdf.Verify(password, stored))
        throw new AuthException();

    var policy = AntechKdf.DefaultRehashPolicy();
    policy.PreferredMemoryKib = 32768;
    if (AntechKdf.NeedsRehashWithPolicy(stored, policy))
    {
        var cfg = AntechKdf.DefaultConfig();
        cfg.MemoryKib = 32768;
        stored = AntechKdf.HashWithConfig(Encoding.UTF8.GetBytes(password), cfg);
    }
    ```
  </FrameworkContent>
</FrameworkTabs>
