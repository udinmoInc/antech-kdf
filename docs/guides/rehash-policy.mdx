Applications evolve memory targets over time. A rehash policy compares the parameters embedded in a stored string to your current floor and preference.

```rust
use antech_kdf::{needs_rehash, needs_rehash_with_policy, RehashPolicy};

if needs_rehash(&stored)? {
    // default policy (16 MiB targets)
}

let policy = RehashPolicy::builder()
    .minimum_memory_mib(16)
    .preferred_memory_mib(32)
    .preferred_fan_in(2)
    .preferred_output_length(32)
    .build();

if needs_rehash_with_policy(&stored, &policy)? {
    // upgrade after successful verify
}
```

A rehash is signaled when stored memory, fan-in, or output length is below the policy targets.

<Tip>
Always verify successfully before spending another full derive on an upgrade.
</Tip>
