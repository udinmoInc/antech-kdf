## Defaults

```rust
let stored = antech_kdf::hash(password)?;
```

Uses random salt + default 16 MiB CombinedFrontier profile.

## Explicit config

```rust
let stored = antech_kdf::hash_with_config(password, &config)?;
```

## Deterministic KATs only

```rust
let stored = antech_kdf::hash_with_config_and_salt(password, salt, &config)?;
```

<Warning>
Do not use fixed salts in production authentication. Reserve `hash_with_config_and_salt` for conformance and interop tests.
</Warning>

<Tip>
Passwords are `AsRef<[u8]>` in Rust — binary secrets are fine. On FFI, use byte APIs so embedded NULs are not truncated.
</Tip>
