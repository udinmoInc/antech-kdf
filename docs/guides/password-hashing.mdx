Most applications call `hash` and store the returned string. Reach for configuration only when you need a non-default memory profile or salt length. Digests are portable across languages at the same release version.

## Default profile

```rust
let stored = antech_kdf::hash(password)?;
```

Random salt, **16 MiB** CombinedFrontier, **32**-byte digest. This is the profile review materials target.

## Explicit configuration

```rust
let stored = antech_kdf::hash_with_config(password, &config)?;
```

Validation runs before any derive. Invalid bounds fail as configuration errors in Rust and as `ANTECH_INVALID_CONFIG` on the FFI.

## Deterministic helper (tests only)

```rust
let stored = antech_kdf::hash_with_config_and_salt(password, salt, &config)?;
```

Use this for conformance vectors and interop checks. Authentication flows should keep random salts so identical passwords do not produce identical stored strings.

## Cross-language examples

<FrameworkTabs frameworks={['Rust', 'Python', 'TypeScript']}>
  <FrameworkContent framework="Rust">
    ```rust
    use antech_kdf::{hash_with_config, AntechConfig};
    let cfg = AntechConfig::builder().memory_mib(16).build()?;
    let stored = hash_with_config(b"secret", &cfg)?;
    ```
  </FrameworkContent>
  <FrameworkContent framework="Python">
    ```python
    import antech_kdf
    cfg = antech_kdf.Config.default()
    stored = antech_kdf.hash_with_config(b"secret", cfg)
    ```
  </FrameworkContent>
  <FrameworkContent framework="TypeScript">
    ```typescript
    import { hashWithConfig, defaultConfig } from "antech-kdf";
    const cfg = defaultConfig();
    const stored = hashWithConfig("secret", cfg);
    ```
  </FrameworkContent>
</FrameworkTabs>

<Tip>
In Rust, passwords are bytes. On FFI, call the `*_bytes` entry points when the secret may contain NUL.
</Tip>

## What not to do

| Anti-pattern | Prefer |
|---|---|
| Hashing in application code with a homemade loop | Raise `memory_mib` via config |
| Storing salt in a second column and rebuilding strings | Persist the library string as-is |
| Switching to research graphs for “speed” | Stay on CombinedFrontier |
