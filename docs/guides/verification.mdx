```rust
let ok = antech_kdf::verify(password, &stored)?;
```

`verify` parses the string, rebuilds config, re-derives with the embedded salt, and compares digests in constant time.

## Outcomes

| Result | Meaning |
|---|---|
| `Ok(true)` | Password matches |
| `Ok(false)` | Password does not match |
| `Err(_)` | Malformed string or invalid embedded parameters |

On the FFI, a mismatch is `ANTECH_VERIFICATION_FAILED` (status `1`), while parse failures are `ANTECH_INVALID_HASH`.

<Note>
Surface `Err` / invalid-hash as an infrastructure problem to operators. Do not tell end users “wrong password” when the stored string itself is corrupt.
</Note>
