Antech APIs are synchronous. A default **16 MiB** derive does not belong on a Node event-loop tick or a Tokio worker that also serves HTTP. Offload hashing so request handlers stay responsive.

| Runtime | Pattern |
|---|---|
| Tokio | `spawn_blocking` or a dedicated pool |
| Node | worker threads, or sync calls outside hot paths |
| .NET | `Task.Run` |
| Python asyncio | `asyncio.to_thread` |

## Capacity sketch

```text
peak_concurrent_verifies × memory_per_hash  ≤  host_scheduler_ceiling
```

Keep interactive login verifies short and bounded by the scheduler. Push bulk migrations and password-file audits to offline workers.

<Tip>
If your framework offers a built-in “CPU-bound work” executor, use it. Antech is closer to compression than to a network I/O await.
</Tip>
