Antech APIs are synchronous. A default 16 MiB derive is inappropriate on an async executor thread.

| Runtime | Pattern |
|---|---|
| Tokio | `spawn_blocking` / dedicated thread pool |
| Node | `worker_threads` or sync call outside hot paths |
| .NET | `Task.Run` |
| Python asyncio | `asyncio.to_thread` |

<Tip>
Batch offline migrations on worker fleets; keep interactive login verifies bounded by your scheduler ceiling.
</Tip>
