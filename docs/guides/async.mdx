title: "Async and non-blocking guidance"
sidebarTitle: "Async"
description: "Run Antech derives off the event loop; hashing is CPU- and memory-bound."

---

Antech APIs are synchronous. A default 16 MiB derive does not belong on a Node event-loop tick or a Tokio worker that also serves HTTP.

| Runtime | Pattern |
|---|---|
| Tokio | `spawn_blocking` or a dedicated pool |
| Node | worker threads, or sync calls outside hot paths |
| .NET | `Task.Run` |
| Python asyncio | `asyncio.to_thread` |

<Tip>
Keep interactive login verifies short and bounded by the scheduler. Push bulk migrations to offline workers.
</Tip>
