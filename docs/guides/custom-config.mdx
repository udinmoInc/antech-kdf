Increase memory when you can afford defender cost and want a harder offline attack. Keep block size and CombinedFrontier unless you have a specific reason to change them — digests and review evidence assume those defaults.

```rust
let cfg = antech_kdf::AntechConfig::builder()
    .memory_mib(32)
    .salt_length(16)
    .fan_in(2)
    .graph(antech_kdf::GraphKind::CombinedFrontier)
    .build()?;
```

## Choosing a memory step

| Profile | When it fits |
|---|---|
| 16 MiB | Default interactive login on small hosts |
| 32 MiB | Stronger offline cost when verify latency is still acceptable |
| Higher | Batch / offline rehash workers, not typically hot login paths |

Measure verify latency on your hardware before rolling a new preferred memory into `RehashPolicy`.

## Validation

Invalid combinations fail at `build()` (Rust) or with `ANTECH_INVALID_CONFIG` (FFI). Bounds are listed in the [configuration reference](../reference/configuration-reference).

<Warning>
Do not change graph tag or construction constants to “tune performance.” That creates a different KDF, not a faster Antech.
</Warning>
