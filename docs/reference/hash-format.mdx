```text
$antech$v2$m=<kib>,s=<salt_len>,b=<block>,f=<fan>,g=<graph>,l=<out>$<salt_hex>$<digest_hex>
```

## Rules

- Parameter section is comma-separated `key=value`
- Required keys: `m`, `s`, `b`, `f`, `g`, `l`
- Duplicate keys rejected
- Unknown keys rejected
- Salt/digest are lowercase hex with lengths matching `s` and `l`
- Version must be `v2` — `v1` is rejected outright

Implemented in `antech-kdf-format`. Applications should treat the full string as opaque storage except for logging/redaction policies.
