Header: `bindings/c/antech_kdf.h`. Shared library: `antech_kdf_ffi` (platform extension).

## Status codes

| Code | Name |
|---|---|
| `0` | `ANTECH_OK` |
| `1` | `ANTECH_VERIFICATION_FAILED` |
| `-1` | `ANTECH_INVALID_INPUT` |
| `-2` | `ANTECH_INVALID_HASH` |
| `-3` | `ANTECH_INTERNAL_ERROR` |
| `-4` | `ANTECH_INVALID_CONFIG` |

## Structs

```c
typedef struct AntechConfig {
    uint32_t memory_kib;
    uint32_t salt_length;
    uint32_t block_size;
    uint32_t fan_in;
    uint32_t graph;
    uint32_t output_length;
} AntechConfig;

typedef struct AntechRehashPolicy {
    uint32_t minimum_memory_kib;
    uint32_t preferred_memory_kib;
    uint32_t preferred_fan_in;
    uint32_t preferred_output_length;
    uint32_t preferred_secret_required;
    uint32_t preferred_associated_data;
} AntechRehashPolicy;
```

## Optional secret / AD

`antech_hash_with_inputs_bytes`, `antech_hash_with_inputs_and_salt`, `antech_verify_with_inputs_bytes`:

| Pointer | Length | Meaning |
|---|---|---|
| `NULL` | `0` | Absent |
| non-`NULL` | `0` | Present but empty |
| non-`NULL` | `N` | Present with `N` bytes |
| `NULL` | `>0` | `ANTECH_INVALID_INPUT` |

Secret and AD bytes are never written into the encoded hash.

## Ownership

- Strings from hash helpers: free with `antech_free`
- Null `antech_free` is a no-op
- Empty passwords: null pointer allowed only when length is `0`

## Threading

Entry points are thread-safe. Concurrent calls share the host resource scheduler.
