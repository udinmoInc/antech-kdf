Shared validation applies in Rust builders and FFI POD structs. Invalid values fail closed before derive.

## AntechConfig

| Field | Default | Bounds |
|---|---|---|
| `memory` / `memory_kib` | 16384 KiB | 1024…1048576 |
| `salt_length` | 16 | 8…256 |
| `block_size` | 32 | power of two in 16..=64 |
| `fan_in` | 2 | 2…8 |
| `graph` | CombinedFrontier (`3`) | `1`…`3` |
| `output_length` | 32 | 8…128 |
| `secret_required` | `false` | Public flag only (`sk=1` in encoding); secret bytes never stored |
| `associated_data_length` | `None` | When `Some(n)`, encode `adl=n`; AD bytes never stored (`n` ≤ 65536) |

Also requires `memory_bytes / block_size >= 64`.

### Optional derive inputs (not stored in the hash)

| Input | Bound | Notes |
|---|---|---|
| Secret | 0…1024 bytes | `None` = unused; `Some` (including empty) binds into the seed |
| Associated data | 0…65536 bytes | Public context; same presence rules as secret |

Limits are DoS / seed-input bounds for the canonical construction, not Argon2 copies.

## Graph tags

| Value | Kind |
|---|---|
| `1` | ReducedCriticalPath |
| `2` | CacheLocality |
| `3` | CombinedFrontier (default) |

## RehashPolicy

| Field | Default |
|---|---|
| `minimum_memory` | 16 MiB |
| `preferred_memory` | 16 MiB |
| `preferred_fan_in` | 2 |
| `preferred_output_length` | 32 |
| `preferred_secret_required` | `false` (when true, hashes without `sk=1` need rehash) |
| `preferred_associated_data` | `false` (when true, hashes without `adl=` need rehash) |

Shared schema JSON: `sdk/schema.json`.
