Antech is an open-source password key-derivation function for hosts that cannot dedicate large Argon2-style working sets, but still want offline attack cost that holds up when defender memory is modest. The shipping profile walks a **combined-frontier** graph in roughly **16 MiB**. Work is `memory / block_size` — there is no separate iteration-count knob.

## Install

Rust services link the API crate directly:

```toml
[dependencies]
antech-kdf = "0.1"
```

Other languages need a release build of the native library first:

<FrameworkTabs frameworks={['Unix', 'Windows']}>
  <FrameworkContent framework="Unix">
    ```bash
    ./sdk/scripts/build-native.sh
    pip install -e bindings/python   # or npm / go / etc.
    ```
  </FrameworkContent>
  <FrameworkContent framework="Windows">
    ```powershell
    ./sdk/scripts/build-native.ps1
    pip install -e bindings/python
    ```
  </FrameworkContent>
</FrameworkTabs>

Set `ANTECH_KDF_LIB` if the loader cannot find `sdk/native`. Full per-language notes live under [SDKs](./sdk/overview).

## Hash and verify

```rust
use antech_kdf::{hash, verify, needs_rehash};

let stored = hash("correct_horse_battery_staple")?;
assert!(verify("correct_horse_battery_staple", &stored)?);
assert!(!needs_rehash(&stored)?);
```

Defaults: **16 MiB**, block size **32**, fan-in **2**, CombinedFrontier (`g=3`), random 16-byte salt, 32-byte digest. Persist the returned `$antech$v2$…` string only.

## How hashing works

1. Bind password and salt into a domain-separated seed.
2. Walk the CombinedFrontier dependency graph over `memory / block_size` blocks.
3. Finalize a digest of the configured output length.
4. Encode parameters, salt, and digest as `$antech$v2$…`.

`verify` parses that string, rebuilds config, re-derives with the embedded salt, and compares digests in constant time.

| Knob | Default |
|---|---|
| Memory | 16 MiB |
| Block size | 32 bytes |
| Fan-in | 2 |
| Graph | CombinedFrontier (`g=3`) |
| Salt length | 16 bytes |
| Output length | 32 bytes |

```text
$antech$v2$m=<kib>,s=<salt_len>,b=<block>,f=<fan>,g=<graph>,l=<out>$<salt_hex>$<digest_hex>
```
