Antech is a password key-derivation function for hosts that cannot dedicate large Argon2-style working sets, but still want offline attack cost that holds up when defender memory is modest. The shipping profile walks a **combined-frontier** graph in roughly **16 MiB**. Work is `memory / block_size` — there is no separate iteration-count knob.

## What Antech does

Use Antech when you need a compute-memory password hash with a small working set, portable `$antech$v2$` strings, and thin multi-language bindings over a single Rust core. Prefer **Argon2id** for public production auth until independent review concludes.

## Defaults

| Knob | Default |
|---|---|
| Memory | 16 MiB |
| Block size | 32 bytes |
| Fan-in | 2 |
| Graph | CombinedFrontier (`g=3`) |
| Salt length | 16 bytes |
| Output length | 32 bytes |

```text
$antech$v2$m=<kib>,s=<salt_len>,b=<block>,f=<fan>,g=<graph>,l=<out>$<salt_hex>$<digest_hex>
```

<Warning>
Antech is experimental. Prefer Argon2id for production password storage until review materials in `research/security-review/` are complete and you accept residual risk.
</Warning>
