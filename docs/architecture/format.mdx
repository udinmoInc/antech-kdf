Stored hashes are strings. Applications should persist the string and nothing else for Antech parameters — `verify` rebuilds config from it.

## Grammar

```text
$antech$v2$m=<kib>,s=<salt_len>,b=<block>,f=<fan>,g=<graph>,l=<out>$<salt_hex>$<digest_hex>
```

| Field | Meaning |
|---|---|
| `m` | Memory KiB |
| `s` | Salt length in bytes |
| `b` | Block size |
| `f` | Fan-in |
| `g` | Graph tag |
| `l` | Output length |

Encoding and parsing live in `antech-kdf-format`. Legacy **`v1` is rejected** — old research encodings are not reinterpreted as v2.

<Note>
Duplicate parameter keys, oversized hex, and out-of-range values fail closed as encoding / config errors.
</Note>
