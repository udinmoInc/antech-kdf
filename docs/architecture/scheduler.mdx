title: "Resource scheduler"
sidebarTitle: "Scheduler"
description: "BoundedResourceScheduler caps concurrent hashing memory on a host."
order: 14
---

`AntechConfig` sets memory for **one** derive. Separately, `BoundedResourceScheduler` enforces a **host-wide** ceiling so many concurrent verifies cannot over-commit RAM. The default ceiling is **128 MiB** across in-flight jobs.

```text
AntechConfig.memory     →  bytes for a single derive
BoundedResourceScheduler →  acquire / release permits for concurrency
```

When permits are exhausted, calls fail with a resource error instead of allocating past the policy.

<Note>
The scheduler does not choose a safe per-hash memory for you. Pick a profile that matches your threat model, then let the scheduler protect the machine under load.
</Note>
