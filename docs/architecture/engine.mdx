## Public helpers

- `hash` / `hash_with_config` — random salt, encoded string
- `hash_with_config_and_salt` — fixed salt for KATs / interop (not the default production path)
- `verify` — parse → derive with stored salt → constant-time compare
- `needs_rehash*` — compare stored params to policy

Construction version and domain separation constants are fixed in core; do not change them casually — digests and review vectors depend on them.
