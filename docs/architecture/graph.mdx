Antech’s cost comes from a password-dependent DAG over memory blocks. Production hashing defaults to **CombinedFrontier**.

## CombinedFrontier

Parents mix a local frontier with far / scatter edges so a reduced-memory attacker cannot simply drop large regions of the address space and still match the digest.

| Constant | Value |
|---|---|
| Frontier width | 64 |
| Tile blocks | 512 |
| Mix rounds | 4 |

The graph kind is mixed into the seed and stored as `g=` in the encoded hash. Changing graph changes digests.

## Other kinds

`ReducedCriticalPath` (`g=1`) and `CacheLocality` (`g=2`) remain available for research contrast. They are not the default review target.

Attack measurements and limitations are documented in `research/security-review/` and `research/docs/`.
