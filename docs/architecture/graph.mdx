Antech’s cost comes from a password-dependent DAG over memory blocks. Production hashing defaults to **CombinedFrontier** (`g=3`). The graph kind is mixed into the seed, so swapping graphs changes digests even when memory and block size stay fixed.

## CombinedFrontier

Parents mix a local frontier with far / scatter edges so a reduced-memory attacker cannot simply drop large regions of the address space and still match the digest.

| Constant | Value |
|---|---|
| Frontier width | 64 |
| Tile blocks | 512 |
| Mix rounds | 4 |

Intuition: each node depends on recent frontier state **and** on distant tiles. That coupling is what makes naive TMTO shortcuts incorrect for the shipping profile.

## Other kinds

| Tag | Name | Role |
|---|---|---|
| `3` | CombinedFrontier | Default review target |
| `1` | ReducedCriticalPath | Research contrast |
| `2` | CacheLocality | Research contrast |

Keep `CombinedFrontier` for any application path that stores passwords. Use the other tags only when you intentionally compare attack surfaces in `research/`.

## Where the graph shows up

```text
seed  ← mix(password, salt, graph_tag, …)
DAG   ← parents(i, fan_in, graph)
digest ← finalize(seed, state, last_block, graph)
string ← …,g=<tag>,…
```

Attack measurements and known limitations live in `research/security-review/` and `research/docs/`.
