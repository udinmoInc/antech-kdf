The CLI wraps the same production API as the Rust crate. Use it for smoke tests, operator tooling, and quick KAT checks — not as a second crypto path.

```bash
cargo run -p antech-kdf-cli -- hash "password"
cargo run -p antech-kdf-cli -- verify "password" "$HASH"
```

## Expected behavior

| Command | Result |
|---|---|
| `hash` | Prints a `$antech$v2$…` string on success |
| `verify` | Exit `0` on match, non-zero on mismatch or parse failure |

Defaults match the library: **16 MiB**, CombinedFrontier, random salt.

<Tip>
Prefer piping passwords from a secret store rather than leaving them in shell history. Quote carefully on Windows PowerShell.
</Tip>
