# Variant K1 — Parallelism Reduction via Candidate Dynamic State Feedback

## Purpose
Variant K1 investigates candidate-dependent state feedback to counter parallel offline password-guessing on SIMD CPU vector extensions and GPU warp execution units.

---

## Construction & Mechanics
During the sequential memory dependency passes, Variant K1 modifies the ARX step rotation amounts and byte values dynamically based on password input bytes:

```text
S_{i+1} = ARX(S_i, Block[Addr_1] ^ Block[Addr_2], pwd_byte)
```

Because every candidate password drives a unique state evolution sequence, SIMD/AVX multi-candidate vectorization and GPU SIMT warp threads experience high branch and instruction divergence.

## Known Limitations
Data-dependent memory accesses introduce potential cache-timing side-channel concerns on multi-tenant hardware. Further analysis is required to evaluate hybrid data-independent initial filling passes.
