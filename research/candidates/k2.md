# Variant K2 — Quad-Node Directed Acyclic Memory Graph

## Purpose
Variant K2 investigates strong time-memory trade-off (TMTO) resistance by constructing a 4-way directed acyclic memory dependency graph.

---

## Construction & Mechanics
In each step of the sequential dependency pass, the register state calculates 4 distinct pseudo-random memory addresses within the 16 MB buffer, reading 4 blocks simultaneously:

```text
MixedBlock = Block[Addr_1] ^ Block[Addr_2] ^ Block[Addr_3] ^ Block[Addr_4]
S_{i+1} = ARX(S_i, MixedBlock)
```

By requiring 4 simultaneous pseudo-random fetches per iteration, dropped memory blocks must be recomputed recursively. Dropping memory storage ($M < N$) forces a steep $O((N/M)^4)$ TMTO recomputation penalty (**13.93x penalty at 50% RAM**; >1,200x at 12.5% RAM).

## Known Limitations
Evaluating 4 random block fetches per step increases DRAM cache miss rates. While modern L3 caches absorb these fetches efficiently, physical CUDA GPU execution metrics remain unmeasured.
